# 3D-Object-Detection-LiDAR-Point-Cloud
This repository provides you with a ROS2 workspace to evaluate the PointPillars Architecture on a real-world recorded rosbag file.  

## Methodology
For this project, we will use the PointPillars Architecture for 3D Object Detection on real 3D LiDAR point clouds, assigning a bounding box and a class to every object in the input scene.
