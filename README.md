# 3D-Object-Detection-LiDAR-Point-Cloud
This repository provides you with a jupyter notebook to train and customize the model and ROS2 workspace to evaluate the trained model on a real-world recorded rosbag file suited to your application. 

## Methodology
For this project, we will use the PointPillars Architecture for 3D Object Detection on real 3D LiDAR point clouds, assigning a bounding box and a class to every object in the input scene. We will walk through the following steps -

- Load dataset for 3D object detection
- Preprocess those input point clouds and labels
- Creating a Tensorflow model architecture
- Setting training parameters and train the model
- Perform inference on the model

- Later, we evaluate the trained model as a checkpoint file on a rosbag
